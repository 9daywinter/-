# 可行性分析报告：个人版 App 简化 + 微信小程序

项目名称：拼时间（大学生日程工具）｜ 日期：2026-11-14 ｜ 依据：全量代码审查（app/ 约 6600 行 + server/ 约 2000 行）+ 平台规则核对

---

## 0. 结论速览

| 方案 | 可行性 | 开发工作量 | 外部等待 | 结论 |
|------|--------|-----------|---------|------|
| 一：APK 简化为个人版 | ✅ 高 | 0.5~1 天 | 无 | **立即可做**，纯删代码，无技术风险 |
| 二：微信小程序（个人版） | ✅ 高 | 2~4 天 | 审核约 1~7 天/次 | **代码可行**（当初选 uni-app 就是为这个），主要成本在**平台合规**而非开发 |
| 附：小程序版组队/群组功能 | ⚠️ 低 | — | — | 个人主体小程序无法使用社交类目，**建议小程序版砍掉组队**（与方案一方向一致，正好共用一套简化代码） |

两个方案共用同一个 FastAPI 后端和 90% 以上的前端代码，建议按"先简化、后移植"的顺序一次做完。

### 1.2 对移植小程序有决定性意义的三个代码事实

1. **浏览器 API 已全部用条件编译隔离**：`import.vue`/`voice.vue` 中的 `document.createElement`、`FileReader`、`window.isSecureContext` 等都包在 `#ifdef H5` / `#ifdef APP-PLUS` 里，MP-WEIXIN 编译不会带入 → 无需大改。
2. **语音链路天然兼容小程序**：APK 路径 = `uni.getRecorderManager()` 录音 → `getFileSystemManager().readFile({encoding:'base64'})` → POST base64 给后端 ASR。`getRecorderManager` 和 `getFileSystemManager` 在微信小程序同样可用，只需把该分支的条件编译扩展到 MP-WEIXIN。
3. **唯一必炸点**：`utils/api.js:3-7` 用 `location.hostname` 推导后端地址，小程序无 `location`，会回落到 `http://localhost:8000`。**必须加 `#ifdef MP-WEIXIN` 指定固定地址**（或改走云托管通道）。

## 2. 方案一：APK 简化为个人版

### 2.1 砍留清单

**砍（组队相关，全部可独立摘除）：**
- 前端：`pages/group/group.vue` 整页 + `pages.json` 注册 + `profile.vue` 群组卡片和 `goGroup()` 跳转（`profile.vue:100-109,193`，全项目仅此一处入口，摘除干净）
- 后端：`routers/groups.py`（443 行）+ `main.py` 里的注册 + `models.py` 中 Group/GroupMember 模型（SQLite 旧表留着无害，可不动）
- `events` 表的定档确认相关字段/接口随 groups 一并失去调用方，可留可删（建议先留，零成本）

**留（个人价值核心）：**
- 课表引擎、AI 导入、语音/文字速记、DDL+建议、冲突检测 —— 全部保留
- **口令同步建议保留**：个人版手机+电脑/换手机同步依然需要它，且零维护成本
- `conflict.py` 保留：它检测的是"我的课 vs 我的日程"冲突，不是组队功能

### 2.2 可行性评估

- **技术**：纯删法，无耦合风险（群组功能在上次 D4 是按独立模块加的，入口单一）
- **部署**：个人使用后端压力≈0。三档选择：本机跑（开机启动 uvicorn）/ 局域网 NAS / 最低配云服务器。注意手机 4G 下访问家里机器需要内网穿透；最省心仍是一台轻量云
- **成本**：无新增。LLM/ASR 无 Key 时全功能可用（规则解析兜底），Key 只是增强

### 2.3 工作量

约 **0.5~1 天**（删代码 0.5 天 + 回归测试 + 重新云打包 APK 0.5 天）。

## 3. 方案二：微信小程序

### 3.1 技术可行性：高

uni-app 的选型红利兑现：`npm run build:mp-weixin`（HBuilderX 发行→小程序）即可产出微信小程序工程，用微信开发者工具打开。前述代码审查确认浏览器 API 已隔离、语音/上传链路接口在小程序均有对应实现。

**代码适配清单（按必改→可选排序）：**

| # | 文件 | 改动 | 量级 |
|---|------|------|------|
| 1 | `utils/api.js` | BASE 加 `#ifdef MP-WEIXIN` 分支：填云托管环境或固定 HTTPS 域名 | 小 |
| 2 | `manifest.json` | `mp-weixin.appid` 填注册后的小程序 appid | 配置 |
| 3 | `voice.vue` | 录音读 base64 的分支条件编译扩展到 MP-WEIXIN（复用现有 APP 分支代码） | 小 |
| 4 | `import.vue` | 图片转 base64 补 MP-WEIXIN 分支（同上，`getFileSystemManager` 读 `chooseImage` 的 tempFilePath）；docx/xlsx 文件选择在小程序改用 `wx.chooseMessageFile`（从聊天记录选文件）或直接砍掉该入口，只留截图+粘贴文本 | 中 |
| 5 | `pages.json` | 建议加 tabBar（课表/DDL/我的 三栏），小程序用户习惯底部导航 | 中 |
| 6 | 隐私接口 | 调摄像头/麦克风前接 `wx.requirePrivacyAuthorization`（或依赖基础库自动弹出） | 小 |
| 7 | `index.vue` 课表网格 | 纯 CSS 实现、无 DOM 操作，理论兼容；需真机验证滑动切周流畅度 | 验证 |

前端改动合计估计 1~2 天；后端**零改动**（FastAPI 原样部署）。

### 3.2 平台合规五道关卡（真正的成本所在）

| # | 关卡 | 规则 | 对本项目 | 对策 |
|---|------|------|---------|------|
| 1 | 主体与类目 | 个人主体可选类目有限；**"社交"类目（用户间互动/群组）不对个人开放** | 组队/碰撞功能在小程序版**过审风险高** | 小程序版砍组队（与方案一一致）；工具类目发个人日程工具无障碍 |
| 2 | 请求域名白名单 | 正式版只能请求 **HTTPS + 已备案** 且已在后台配置的域名；开发期可勾"不校验合法域名"连本机 uvicorn | 当前 `http://host:8000` 不满足 | 二选一，见 3.3 部署路径 |
| 3 | 用户隐私保护指引 | 2023-09 起强制：后台填写隐私指引，**声明麦克风/摄像头/相册**用途，未声明调用对应 API 直接失败 | 语音+截图导入都用到 | 后台如实声明"仅用于解析用户自己的课表/语音，不存储"；半天工作量 |
| 4 | 消息通知 | 小程序**无本地推送/离线提醒**；一次性订阅消息个人主体可用（用户每订阅一次可推一条）；长期订阅仅公共服务类目 | "下节课提醒"（PRD P1）在小程序**做不了**离线版 | 当前原型本就未实现提醒 → 无损失；后期可做弱版（打开时看 + 一次性订阅） |
| 5 | 代码审核 | 首次审核 1~7 天，被拒一轮很常见（类目不符/隐私声明不全/AI 功能用途说明） | AI 仅解析用户自己输入、无 UGC 对外展示 → 风险低 | 提审材料写清 AI 用途；预留 1~2 轮被拒修改时间 |

其他已核对无影响的点：包体积远小于主包限制；`uni.getStorageSync`（口令存储）小程序可用；`uni.request` 超时上限 60s > 现设 20s；个人主体免注册费、无需认证。

### 3.3 部署路径二选一（后端怎么被小程序访问到）

| 路径 | 前置条件 | 周期 | 成本 | 适用 |
|------|---------|------|------|------|
| **A. 微信云托管（推荐起步）** | FastAPI 打 Docker 镜像推上云托管，小程序端 `wx.cloud.callContainer` 调用 | **即时**，当天上线 | 按量计费、可缩容到 0，个人量级月成本极低 | **无需自己买域名、无需备案**（callContainer 走微信通道，不占白名单——以官方文档最新说明为准） |
| B. 自有域名 + 备案 | 买域名 + 境内服务器 ≥3 个月 + ICP 备案 + HTTPS 证书 | 备案 1~3 周 | 域名 + 轻量服务器约几十元/月 | 想长期稳定、脱离云托管时再走 |

建议：A 起步验证（`api.js` 封一层，后端地址一处可换），需要时再平滑迁 B。FastAPI 打 Docker 镜像是标准操作（requirements.txt 仅 5 个依赖），迁移成本约 0.5 天。

### 3.4 工作量与周期汇总

| 阶段 | 工作量 | 备注 |
|------|--------|------|

## 4. 建议实施路径

```
第 1 步  方案一：简化个人版（0.5~1 天）
         删 group → 回归 → 重新打包 APK → 自己先日用起来
         ※ 这一步同时为小程序清掉了社交合规雷
第 2 步  注册个人小程序 + 后端上云托管（并行，0.5 天 + 等审核）
第 3 步  小程序代码适配（1~2 天）→ 开发者工具连本机调通
第 4 步  切 callContainer → 填隐私指引 → 提审（1~7 天）
第 5 步  过审上线；日常自用反馈迭代
         远期可选：自有域名备案迁移 / 订阅消息弱提醒 / 组队功能回 H5 版保留
```

**保留组队功能的去处**：组队碰撞是产品的增长亮点，不必删除代码——APK/H5 版保留完整功能，小程序版发布个人简化版。一套代码两个发行目标，uni-app 条件编译天然支持（`#ifndef MP-WEIXIN` 包住群组入口即可）。

## 5. 风险与对策汇总

| 风险 | 等级 | 对策 |
|------|------|------|
| 小程序审核因 AI 功能/隐私声明被拒 | 中 | 材料写清"仅解析用户自身数据、不对外展示"；预留一轮修改 |

| `index.vue` 课表网格真机性能 | 低 | 纯 CSS 无 DOM 操作，预期良好；不行再虚拟列表优化 |
| 备案流程长（若走路径 B） | 低 | 起步用云托管绕开，不阻塞 |

## 附：本报告核实过的代码事实

- 组队入口全项目仅 `profile.vue:193` 一处跳转 + `pages.json` 注册 → 可干净摘除
- `voice.vue` 录音→base64→`/api/ai/voice-upload` 链路在 mp-weixin 有等价 API
- `import.vue` 的 DOM 操作全部在 `#ifdef H5` 内；`api.js` 的 `location` 依赖是唯一无条件编译的平台耦合点
- 后端无任何客户端形态耦合（纯 REST + X-User 头），小程序/APK/H5 可共用
- LLM（GLM-4V/GLM-4-flash，OpenAI 兼容协议）与 ASR（whisper/paraformer）均为服务端配置，无 Key 时规则解析全量兜底
