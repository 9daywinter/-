# 需求规格说明书（SRS）

项目名称：大学生日程管理工具（暂定名"拼时间"）
版本：v0.2 ｜ 日期：2026-11-07 ｜ 状态：四天骨架版

---

## 1. 引言

### 1.1 目的
本文档定义"拼时间"的功能与非功能需求，作为设计、开发、测试与验收的依据。预期读者：开发人员、指导老师 / 评审、测试人员。

### 1.2 范围
一款面向大学生的日程管理 App：以课表为时间骨架，以 DDL 为驱动，支持语音速记、AI 课表导入、推荐式（非强制）安排，以及组队空闲查询（碰撞）。提供 Android APK 与 H5 双形态。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 教学周 | 以学期第一周周一为基准推算的周序号（第 1~N 周） |
| 节次 | 高校作息单位（第 1 节、第 2 节…），每校有对应时刻表 |
| 单双周 | 课程仅在奇数周或偶数周开设 |
| DDL | Deadline，作业/考试等截止时间 |
| 忙闲位图 | 以 30 分钟为粒度的周时间占用图，用于空闲计算 |
| 挡时间 | 用户手动标记"该时段有事"，不产生正式日程 |
| 置信度三档 | 确定忙 / 可能有事 / 应该空闲 的忙闲判定分级 |

### 1.4 用户画像
- **核心用户**：在校大学生（本科为主）。日程以课表为骨架、DDL 波峰波谷明显、生活事件碎片化且大多不入日程；对"被安排"抵触，对"省事"敏感。
- **次级用户**：研究生（组会/科研节奏）、社团组织者（凑时间开会）。

## 2. 产品概述

**定位一句话**：以课表为骨架、以 DDL 为驱动、能和朋友拼时间的大学生日程工具。

**产品三原则**（贯穿所有需求）：
1. 只建议，不强迫——自动安排一律以建议卡片呈现，用户三键决定；
2. 课表是骨架——一切时间计算基于课表 + 教学周；
3. 一个人也好用——单人功能闭环，组队功能是增益。

## 3. 功能需求

> 编号规则：FR-模块序号。验收标准即测试用例来源。

### 3.1 学期与课表模块（FR-1x）

| 编号 | 需求 | 说明 | 验收标准 |
|------|------|------|---------|
| FR-11 | 设置学期 | 填写学期名、第一教学周周一日期、总周数 | 系统正确返回"当前为第 N 教学周"，跨学期可修改 |
| FR-12 | 手动管理课程 | 增删改课程：名称、教师、地点、星期、节次、周次 | 支持周次数组输入（如 1,3,5..17 表示单周课） |
| FR-13 | 课表周视图 | 按教学周渲染课程网格，可左右切周 | 单双周课程在对应周正确显示/隐藏；当前周高亮 |
| FR-14 | 截图导入课表 | 上传教务系统截图 → AI 解析 → 校对页 → 批量入库 | 主流教务系统截图解析准确率 ≥90%；校对页可逐项修改；批量入库成功 |
| FR-15 | 教学周推算 | 由学期配置自动计算当日教学周 | 开学前返回第 0 周；超总周数封顶 |

### 3.2 语音 / 文字速记模块（FR-2x）

| 编号 | 需求 | 说明 | 验收标准 |
|------|------|------|---------|
| FR-21 | 语音速记 | 按住说话 → ASR 转文字 → AI 抽取意图 → 确认卡片 → 入日程 | 识别 → 解析 → 确认全程 ≤10 秒；确认一键完成 |
| FR-22 | 文字速记 | 文字输入走同一解析链路 | 与语音完全等价（语音是亮点，文字是兜底） |
| FR-23 | 模糊时间解析 | 相对/模糊表达对照课表解析为具体时段 | v1 支持 5 类表达（见 3.6 模糊时间语义表），测试集通过率 ≥80% |

### 3.3 DDL 中枢与推荐模块（FR-3x）

| 编号 | 需求 | 说明 | 验收标准 |
|------|------|------|---------|
| FR-31 | DDL 采集 | 手动添加 / 粘贴群通知文字 / 截图，AI 抽取任务名、课程、截止时间 | 抽取结果先展示校对再入库 |
| FR-32 | DDL 倒计时墙 | 按剩余时间 × 权重分红/黄/绿三档；支持完成打卡 | 逾期自动置灰；倒计时以天/小时显示 |
| FR-33 | 推荐建议卡片 | 计算空闲池 → 按紧迫度生成建议；每张卡片三动作：接受/换时间/忽略 | 接受→写入日程；忽略→记录原因用于降权；**绝不自动写入日程** |
| FR-34 | 手动挡时间 | 日历长按标记"我有事"，不产生正式日程 | 挡的时间段计入个人忙闲，对组内显示为"忙" |

### 3.4 组队空闲查询模块（FR-4x）

| 编号 | 需求 | 说明 | 验收标准 |
|------|------|------|---------|
| FR-41 | 建组与进组 | 远程：邀请链接/口令发群，异地可进；面对面：二维码扫码进组 | 未安装 App 者经浏览器 H5 进组；进组仅需昵称，零填表 |
| FR-42 | 共同空闲 Top3 | 汇总全组成员忙闲位图求交集，按偏好打分输出 Top 3 | 30 分钟粒度；输出各时段全员状态一览 |
| FR-43 | 指定时间查忙闲 | 用户指定任意时间 → 列出每个成员状态 | 状态含置信度三档：确定忙（上课/有安排/挡）/ 可能有事（饭点深夜等）/ 应该空闲 |
| FR-44 | 定档与确认 | 组长从候选定档 → 全员「确认 ✓ / 有冲突 ✗」 | 有人标冲突即回到下一候选；全员确认后写入各自日程（标记群组日程） |
| FR-45 | 隐私默认 | 组内仅暴露忙闲与状态类型，不暴露课程名、事件标题 | 用户可主动选择开放细节（默认关闭） |

### 3.5 概览模块（FR-5x）

| 编号 | 需求 | 说明 | 验收标准 |
|------|------|------|---------|
| FR-51 | 今日概览卡片 | 打开即看：今天的课、临近 DDL、今日建议 | 单屏呈现，无需滚动超过一屏 |

### 3.6 模糊时间语义表（FR-23 细化）

| 用户说 | 解析逻辑 |
|--------|---------|
| "明天下午没课的时候" | 明日 12:00–18:00 − 课表占用 → 剩余空档 |
| "下节课后" | 课表查下一节课结束时间 |
| "周五晚上" | 本周/下周五 18:00–23:00（用户默认作息） |
| "考试周前" | 教学周配置推算考试周起始日 |
| "X 点 / X 点半" | 最近未来时刻的该钟点 |

## 4. 非功能需求

| 编号 | 类别 | 需求 |
|------|------|------|
| NFR-1 | 性能 | 本地接口响应 <200ms（P95）；AI 解析类操作 ≤15s 并有进度提示 |
| NFR-2 | 易用性 | 高频操作（加日程、看课表、查忙闲）≤3 步、可单手完成 |
| NFR-3 | 隐私 | 忙闲数据默认不含内容；用户数据可导出/删除；课表截图不在服务端留存 |
| NFR-4 | 兼容性 | Android 8+（APK）；手机 Chrome/Safari/微信内置浏览器（H5） |
| NFR-5 | 可维护性 | LLM 调用统一封装于"解析服务"模块，模型可配置可替换 |
| NFR-6 | 成本 | 学生量级下 LLM 月成本可控（解析结果缓存，杜绝重复调用） |

## 5. 典型用例

### UC-1 截图导入课表
- **角色**：新生小 A（首次使用）
- **前置**：已安装/打开 H5，已设置学期
- **主流程**：进入"导入课表" → 拍教务系统截图 → AI 解析出 12 门课 → 校对页修正 1 处地点 → 保存 → 周视图正确显示
- **异常流**：解析失败/置信度低 → 提示手动录入，校对页可逐格编辑

### UC-2 语音速记临时日程
- **角色**：大二学生小 B（躺宿舍床上）
- **主流程**：长按麦克风说"明天下午没课的时候提醒我去取快递" → 弹出确认卡（明天 14:00–15:30，取快递）→ 点✓ → 入日程
- **异常流**：明天下午全有课 → 给出"最近的空档"建议供选择

### UC-3 DDL 建议接受
- **角色**：赶 DDL 的小 C
- **主流程**：粘贴群通知"周五 24:00 前交实验报告" → 抽取成功 → DDL 墙黄色卡片 → 系统建议"周三晚 19:00–21:00 空闲，建议写实验报告" → 点"接受" → 周三晚日程出现
- **分支**：点"换时间" → 从空闲池选其他时段；点"忽略" → 选择原因（这周不想做/已有安排）→ 后续降权

### UC-4 宿舍凑时间聚餐（异地可用）
- **角色**：寝室长小 D + 3 名室友（一人在外校交流）
- **主流程**：小 D 建组 → 链接发宿舍群 → 4 人进组（1 人用 H5）→ 查"周六下午"：2 人空闲、1 人上课、1 人可能有事 → 切"共同空闲 Top3" → 选 Top1 定档 → 全员确认 ✓ → 4 人日程同时出现"寝室聚餐"
- **异常流**：有人点"有冲突" → 自动呈现 Top2 候选重新定档

## 6. 竞品分析

| 竞品 | 强项 | 缺什么 |
|------|------|--------|
| WakeUp 课程表 | 课表导入体验好 | 无 DDL 管理、无推荐、无组队 |
| 超级课程表 | 课表 + 校园社区 | 重运营、无空闲碰撞、无语音 |
| 番茄ToDo | 专注锁机 | 无课表语义、无 DDL |
| 系统日历/Google Calendar | 通用日程 | 不懂教学周/节次/单双周，无 AI |

**差异化结论**：课表语义 × DDL 驱动推荐 × 组队空闲查询，三者组合无直接竞品。
